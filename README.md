# ML-Drug-Classification-CICD

Machine Learning CI/CD pipeline for drug classification using Scikit-learn, ONNX, GitHub Actions, CML, and Hugging Face Spaces.

## Project Features

- Train a Random Forest drug classification model.
- Evaluate model performance using accuracy and weighted F1-score.
- Export the trained model to Joblib and ONNX formats.
- Generate evaluation metrics and a confusion matrix.
- Automate model training and evaluation using GitHub Actions.
- Publish evaluation reports using CML.
- Deploy the browser-based application to Hugging Face Spaces.

## Technologies Used

- Python
- Scikit-learn
- ONNX and ONNX Runtime Web
- Git and GitHub
- GitHub Actions
- CML
- Hugging Face Spaces
- HTML and JavaScript

## Disclaimer

This project is an educational demonstration only and is not intended for medical decision-making.
